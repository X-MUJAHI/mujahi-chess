# Chess Helper 2.1.0 — Engine provider switch + MUJAHI API

## Added
- Engine Settings gear in the panel header with three switchable providers persisted in `localStorage` (`ch_engine_provider`):
  - **Hosted API** (`api`, StockfishOnline default)
  - **MUJAHI API** (`mujahi`, MUJAHI Stockfish 19 Render backend with MV3 background service worker and SSE streaming)
  - **Local WASM** (`wasm`, Stockfish.js 19.0.1 Lite single-threaded UCI worker)
- Manifest V3 background service worker (`engine/mujahi-background.js`) and provider adapter (`engine/mujahi-provider.js`) supporting progressive depth batching (D5 -> D10 -> D15) and instant cancellation when board positions change.
- Clean icon fallback (`images/icon.svg`) if `images/xndroid.jpg` is absent.

## Preserved
- StockfishOnline API provider (`api`) as default and its host permission.
- Local WASM (`wasm`) host bridge and UCI search coordinator.
- SuperMode board overlays, arrows (D5/D10/D15), mate alerts, evaluation bar, autoplay, freemium move counter/keys, Lichess integrations, and Xndroid endpoints.

# Chess Helper 2.1.1 — Auto-play timing randomizer

## Added
- Added an optional **Randomize move delay** control inside the existing Settings gear overlay.
- Added editable minimum and maximum delays (0–10000 ms), saved between sessions.
- Selects a fresh independent random delay for each auto-play move; uses the browser crypto random source where available.
- Cancels a pending delayed move when its position becomes stale, the tab is hidden, or auto-play is switched off.

## Preserved
- Existing engine providers, analysis settings, arrows, SuperMode, and board interaction.
- Randomization is off by default, preserving the previous auto-play timing until enabled.

# Chess Helper 2.1.2 — Auto-play source randomization

## Added
- Moved the existing **Auto-play arrow** selector from the main panel into the existing Settings gear overlay.
- Added **Random — Blue / Teal**, which randomly chooses between the Blue (D5) and Teal (D10) engine sources for each of the user's turns.
- Random mode uses whichever of Blue and Teal are enabled in the main panel; if only one is enabled, it uses that source. If neither is enabled, no move is auto-played in random mode.
- Changing the selected auto-play source refreshes the current position so the new selection can take effect without waiting for the next position.

## Preserved
- Existing Green (D15), Teal (D10), and Blue (D5) manual source selections.
- Existing auto-play random delay settings and all existing engine / SuperMode settings.
- Existing default selection remains Green (D15) for new installations and installations without a saved selection.

# Chess Helper 2.1.3 — Other good moves

## Added
- Added an independent **Show alternative moves** setting in the main Settings overlay. It works without enabling SuperMode.
- Added a configurable count of 1–4 alternative moves. The extension requests one additional principal variation from Lichess Cloud Eval to account for the best line, then displays the remaining candidate first moves.
- Added a compact **Other good moves** panel card below the depth arrows, with each alternative move and its white-perspective evaluation.
- Added a manual refresh control and bounded in-memory caching.
- Added a single-request flow for Lichess Cloud Eval and a 60-second cooldown after HTTP 429, following Lichess API guidance.
- Added detection for a board-exposed full FEN where available. When the extension has to fall back to piece-DOM reconstruction, the UI warns that castling/en-passant state may be incomplete.

## Important limitations
- The Hosted API and the existing MUJAHI adapter return one best move per depth; they do not expose a MultiPV setting in this extension package. Therefore these additional suggestions use Lichess Cloud Eval's cached MultiPV data, not the currently selected Stockfish provider.
- Lichess can return no alternatives when a position is not in its cloud-evaluation cache. The returned analysis depth may differ from the selected D5/D10/D15 depth.
- The current piece-DOM FEN fallback does not preserve castling rights or en-passant state. If Chess.com does not expose a full FEN on the board element, treat the displayed cloud alternatives as suggestions to verify rather than authoritative engine analysis for that exact position.

## Preserved
- Existing D5/D10/D15 engine arrows, autoplay source selection, random autoplay delay, provider selection, and SuperMode features.

# Engine provider modes

Open Chess Helper → **Engine Settings** (gear icon in the panel header).

- **Hosted API** (default): keeps the existing `https://stockfish.online/api/s/v2.php` request path and its internet dependency.
- **MUJAHI API**: connects through the extension's Manifest V3 background worker (`engine/mujahi-background.js`) to your MUJAHI Stockfish 19 backend (`https://mujahi-chess.onrender.com`), streaming D5, D10, and D15 snapshots progressively over `/v1/analyze/stream` without exposing `chess.com` in backend CORS.
- **Local WASM**: starts the bundled Stockfish.js 19.0.1 Lite single-threaded UCI worker inside an extension-origin host frame. No engine HTTP request or API key is used. The worker is created on first analysis and destroyed when switching to Hosted API or MUJAHI API.

## Required Stockfish files (for Local WASM only)

Place the matching upstream release files in `engine/`:

- `engine/stockfish-19-lite-single.js` — 28,230 bytes
- `engine/stockfish-19-lite-single.wasm` — 1,845,971 bytes

Official v19.0.1 release assets:

- https://github.com/nmrugg/stockfish.js/releases/download/v19.0.1/stockfish-19-lite-single.js
- https://github.com/nmrugg/stockfish.js/releases/download/v19.0.1/stockfish-19-lite-single.wasm

## Preserved Bubble Image

The floating button uses `images/xndroid.jpg` when present (copy your binary `images/xndroid.jpg` into `extension/images/xndroid.jpg` if downloading from GitHub without binary uploads) and falls back cleanly to `images/icon.svg` otherwise.

function randomIntInclusive(min, max) {
    if (max <= min) return min;
    const range = max - min + 1;
    const cryptoApi = window.crypto;
    if (cryptoApi?.getRandomValues) {
        const limit = Math.floor(0x100000000 / range) * range;
        const sample = new Uint32Array(1);
        let value;
        do { cryptoApi.getRandomValues(sample); value = sample[0]; } while (value >= limit);
        return min + (value % range);
    }
    return min + Math.floor(Math.random() * range);
}

        const finish = completed => {
            if (settled) return;

            if (pendingAutoPlayDelayCancel === cancel) pendingAutoPlayDelayCancel = null;

        };

    });
}

function parseLocalUciInfo(fen, line) {
    const depthMatch = line.match(/(?:^|\s)depth\s+(\d+)/);
    const scoreMatch = line.match(/\bscore\s+(cp|mate)\s+(-?\d+)/);
    const pvMatch = line.match(/\bpv\s+(.+)$/);
    if (!depthMatch || !pvMatch) return null;
    const depth = Number(depthMatch[1]);
    const pv = pvMatch[1].trim();
    const move = pv.split(/\s+/)[0];
    if (!move || move === '(none)' || move === '0000') return null;
    let evaluation = null, mate = null;
    if (scoreMatch) {
        const scoreValue = Number(scoreMatch[2]);
        const whitePov = (fen.split(/\s+/)[1] || 'w') === 'b' ? -1 : 1;
        if (scoreMatch[1] === 'cp') evaluation = (scoreValue / 100) * whitePov;
        else mate = scoreValue * whitePov;
    }
    return { move, evaluation: Number.isFinite(evaluation) ? evaluation : null, mate: Number.isFinite(mate) ? mate : null, continuation: pv, depth, raw: { uci: line } };
}
function settleLocalWasmWaiter(job, waiter, move, error = null) {
    if (waiter.settled) return;
    waiter.settled = true;
    if (waiter.signal && waiter.abortHandler) waiter.signal.removeEventListener('abort', waiter.abortHandler);
    job.waiters = job.waiters.filter(item => item !== waiter);
    if (error) waiter.reject(error); else waiter.resolve(move || null);
}
function resolveLocalWasmWaiters(job, analysis) {
    if (!analysis) return;
    for (const waiter of [...job.waiters]) {
        if (analysis.depth >= waiter.depth) {

            settleLocalWasmWaiter(job, waiter, analysis.move);
        }
    }
}
function finishLocalWasmSearch(job, move, error = null) {
    if (!job || job.finished) return;
    job.finished = true;
    if (error) {
        for (const waiter of [...job.waiters]) settleLocalWasmWaiter(job, waiter, null, error);
    } else {
        const finalMove = move || job.latestAnalysis?.move || null;
        for (const waiter of [...job.waiters]) {
            if (job.latestAnalysis) {
                const cacheKey = `wasm|${job.fen}|${waiter.depth}`;
                setBoundedCache(fenCache, cacheKey, finalMove);
            }
            settleLocalWasmWaiter(job, waiter, finalMove);
        }
    }
    if (localEngineActiveSearch === job) localEngineActiveSearch = null;
    if (localWasmSearches.get(job.fen) === job) localWasmSearches.delete(job.fen);
    Promise.resolve().then(pumpLocalWasmQueue);
}
function handleLocalWasmLine(job, line) {
    if (localEngineActiveSearch !== job || job.finished) return;
    if (line.startsWith('info ')) {
        const analysis = parseLocalUciInfo(job.fen, line);
        if (!analysis) return;
        job.latestAnalysis = analysis;
        const prior = engineAnalysisCache.get(job.fen);
        if (!prior || analysis.depth >= (prior.depth || 0)) {
            engineAnalysisCache.set(job.fen, analysis);
            setBoundedCache(engineAnalysisCache, job.fen, analysis, 120);
            handleSuperModeEngineAnalysis(job.fen, analysis);
        }
        resolveLocalWasmWaiters(job, analysis);
        return;
    }
    if (line.startsWith('bestmove ')) {
        const move = line.split(/\s+/)[1];
        if (job.restartDepth && job.restartDepth > (job.latestAnalysis?.depth || 0) && job.waiters.length) {
            job.started = false;
            job.startedDepth = 0;
            job.maxDepth = job.restartDepth;
            job.restartDepth = 0;
            if (localEngineActiveSearch === job) localEngineActiveSearch = null;
            localEngineSearchQueue.unshift(job);
            Promise.resolve().then(pumpLocalWasmQueue);
            return;
        }
        finishLocalWasmSearch(job, move && move !== '(none)' && move !== '0000' ? move : null);
    }
}
async function pumpLocalWasmQueue() {
    if (localEngineActiveSearch || !localEngineSearchQueue.length) return;
    const job = localEngineSearchQueue.shift();
    if (!job || job.finished) { Promise.resolve().then(pumpLocalWasmQueue); return; }
    if (!job.waiters.length) {
        if (localWasmSearches.get(job.fen) === job) localWasmSearches.delete(job.fen);
        Promise.resolve().then(pumpLocalWasmQueue);
        return;
    }
    localEngineActiveSearch = job;
    try {
        await initializeLocalEngine();
        if (localEngineActiveSearch !== job || job.finished) return;
        if (!job.waiters.length) { finishLocalWasmSearch(job, null); return; }
        job.started = true;
        job.startedDepth = job.maxDepth;
        localEnginePost({ type: 'command', command: `position fen ${job.fen}` });
        localEnginePost({ type: 'command', command: `go depth ${job.startedDepth}` });
    } catch (error) {
        if (!localEngineFailure) failLocalEngine(error);
        else finishLocalWasmSearch(job, null, error);
    }
}
function fetchLocalWasmBestMove(fen, depth, signal, cacheKey) {
    if (signal?.aborted) return Promise.resolve(null);
    if (localEngineFailure) return Promise.reject(localEngineFailure);
    return new Promise((resolve, reject) => {
        let job = localWasmSearches.get(fen);
        if (!job) {
            job = { fen, maxDepth: depth, startedDepth: 0, started: false, finished: false, waiters: [], latestAnalysis: null };
            localWasmSearches.set(fen, job);
            localEngineSearchQueue.push(job);
        } else {
            job.maxDepth = Math.max(job.maxDepth, depth);
        }
        const waiter = { depth, signal, resolve, reject, settled: false, abortHandler: null };
        job.waiters.push(waiter);
        if (signal) {
            waiter.abortHandler = () => {
                settleLocalWasmWaiter(job, waiter, null, localEngineAbortError());
                if (!job.waiters.length) {
                    if (localEngineActiveSearch === job) {
                        try { localEnginePost({ type: 'command', command: 'stop' }); } catch (_) {}
                    } else {
                        localEngineSearchQueue = localEngineSearchQueue.filter(item => item !== job);
                        if (localWasmSearches.get(fen) === job) localWasmSearches.delete(fen);
                    }
                }
            };
            signal.addEventListener('abort', waiter.abortHandler, { once: true });
            if (signal.aborted) { waiter.abortHandler(); return; }
        }
        if (job.latestAnalysis && job.latestAnalysis.depth >= depth) {
            const latest = job.latestAnalysis;
            setBoundedCache(fenCache, cacheKey, latest.move);
            settleLocalWasmWaiter(job, waiter, latest.move);
            return;
        }
        if (!job.started) Promise.resolve().then(pumpLocalWasmQueue);
        else if (job.maxDepth > job.startedDepth) {
            // A later higher-depth request on the same FEN restarts the active search once,
            // preserving existing waiters and any shallower results already delivered.
            job.restartDepth = Math.max(job.restartDepth || 0, job.maxDepth);
            try { localEnginePost({ type: 'command', command: 'stop' }); } catch (_) {}
        }
    });
}

    const now = Date.now();
    if (bonus <= 0 && activeKey) { localStorage.removeItem('ch_active_key'); activeKey = null; }
    if (keyDisplay) {
        if (bonus > 0 && activeKey) {
            keyDisplay.style.display = 'flex';
            document.getElementById('ch-active-key-name').innerText = activeKey;
            document.getElementById('ch-active-key-moves').innerText = bonus;
        } else { keyDisplay.style.display = 'none'; }
    }
    if (cooldownStart > 0 && count >= 200 && bonus <= 0) {
        const timePassed = now - cooldownStart;
        if (timePassed >= SIX_HOURS) {
            localStorage.setItem('ch_move_count', '0');
            localStorage.setItem('ch_cooldown_start', '0');
            hasShownExhaustModal = false;
            textEl.innerText = `Moves: 0/200`;
            if (countdownInterval) clearInterval(countdownInterval);
        } else {
            const timeLeft = SIX_HOURS - timePassed;
            const h = Math.floor((timeLeft / (1000 * 60 * 60)) % 24);
            const m = Math.floor((timeLeft / 1000 / 60) % 60);
            const s = Math.floor((timeLeft / 1000) % 60);
            textEl.innerText = `Resets in ${h}:${m < 10 ? '0' + m : m}:${s < 10 ? '0' + s : s}`;
            textEl.style.color = "#ff4444";
            if (!countdownInterval) countdownInterval = setInterval(updateMoveUI, 1000);
        }
    } else {
        if (countdownInterval) { clearInterval(countdownInterval); countdownInterval = null; }
        textEl.style.color = "var(--ch-text-secondary)";
        textEl.innerText = bonus > 0 ? `Moves: ${count}/200 (+${bonus} Bonus)` : `Moves: ${count}/200`;
    }
}

function getNativeFullFen(boardEl) {
    const candidates = [];
    for (const method of ['getFen', 'getFEN', 'fen']) {
        try { if (typeof boardEl?.[method] === 'function') candidates.push(boardEl[method]()); } catch (_) {}
    }
    for (const value of [boardEl?.fen, boardEl?.position, boardEl?.getAttribute?.('fen'), boardEl?.getAttribute?.('data-fen'), boardEl?.dataset?.fen]) {
        if (typeof value === 'string') candidates.push(value);
    }
    for (const candidate of candidates) {
        if (typeof candidate !== 'string') continue;
        const fields = candidate.trim().split(/\s+/);
        if (fields.length < 4 || !/^[prnbqkPRNBQK1-8/]+$/.test(fields[0]) || !/^[wb]$/.test(fields[1]) || !/^(?:-|K?Q?k?q?)$/.test(fields[2]) || !/^(?:-|[a-h][36])$/.test(fields[3])) continue;

    }

function getFEN() {
    const boardEl = getBoard();
    if (!boardEl) return null;
    const nativeFen = getNativeFullFen(boardEl);
    if (nativeFen) { lastFenWasNativeComplete = true; return nativeFen; }
    lastFenWasNativeComplete = false;
    const pieces = boardEl.querySelectorAll('.piece');
    if (!pieces.length) return null;
    const board = Array(64).fill(null);
    for (const piece of pieces) {
        let type = null, square = null;
        for (const cls of piece.classList) {
            if (!type && pieceToFen[cls]) type = pieceToFen[cls];
            else if (!square && cls.startsWith('square-')) square = cls.slice(7);
        }
        if (type && square && /^[1-8][1-8]$/.test(square)) {
            const file = Number(square[0]) - 1, rank = Number(square[1]);
            board[(8-rank)*8+file] = type;
        }
    }
    const rows = [];
    for (let r=0; r<8; r++) {
        let empty=0, row='';
        for (let c=0; c<8; c++) {
            const value=board[r*8+c];
            if (value===null) empty++;
            else { if (empty) { row+=empty; empty=0; } row+=value; }
        }
        if (empty) row+=empty;
        rows.push(row);
    }
    // Chess.com piece DOM does not expose castling/en-passant state in this fallback.
    return rows.join('/') + ` ${getActiveColor(boardEl)} - - 0 1`;
}

// --- API CALLS ---
const MAX_API_RETRIES = 2; // retries after the first attempt
const RETRY_BASE_MS = 500;
function retryDelay(response, attempt) {
    const retryAfter = response?.headers?.get?.('Retry-After');
    if (retryAfter) {
        const seconds = Number(retryAfter);
        if (Number.isFinite(seconds)) return Math.min(60000, Math.max(250, seconds * 1000));
        const dateDelay = Date.parse(retryAfter) - Date.now();
        if (Number.isFinite(dateDelay) && dateDelay > 0) return Math.min(60000, dateDelay);
    }
    return Math.min(8000, RETRY_BASE_MS * (2 ** attempt));
}
function reportHttpError(service, status) {
    if (status === 429) log(`${service}: HTTP 429 rate limited; retrying with backoff`);
    else if (status === 401) log(`${service}: HTTP 401 unauthorized; check API access`);
    else if (status === 403) log(`${service}: HTTP 403 forbidden; request blocked`);
    else if (status >= 500) log(`${service}: HTTP ${status} server error; retrying`);
    else log(`${service}: HTTP ${status}`);
}
async function fetchJsonWithRetry(url, options, service) {
    for (let attempt = 0; attempt <= MAX_API_RETRIES; attempt++) {
        if (options?.signal?.aborted) return null;
        try {
            const res = await fetch(url, options);
            if (res.ok) return await res.json();
            reportHttpError(service, res.status);
            // Authentication/permission and other client errors won't improve by retrying.
            const retryable = res.status === 429 || res.status >= 500;
            if (!retryable) return false; // terminal client/auth error: report once, don't hammer the endpoint
            if (attempt === MAX_API_RETRIES) return null;
            await sleep(retryDelay(res, attempt));
        } catch (e) {
            if (e?.name === 'AbortError' || options?.signal?.aborted) return null;
            console.warn(`[${service}] Network error (attempt ${attempt + 1}/${MAX_API_RETRIES + 1})`, e);
            if (attempt === MAX_API_RETRIES) return null;
            await sleep(Math.min(8000, RETRY_BASE_MS * (2 ** attempt)));
        }
    }
    return null;
}

async function loadOtherGoodMoves(fen) {
    const cfg = window.chessHelper?.otherGoodMoves || {};
    const count = Math.max(1, Math.min(4, Number.parseInt(cfg.count, 10) || 2));
    if (!cfg.enabled || !fen) {
        if (otherGoodMovesController) otherGoodMovesController.abort();
        otherGoodMovesController = null;
        otherGoodMovesRequestKey = '';
        renderOtherGoodMovesState({ count });
        return;
    }

    const requestKey = `${fen}|${count}`;
    const fenComplete = lastFenWasNativeComplete;
    otherGoodMovesCurrentFen = fen;
    if (otherGoodMovesRequestKey === requestKey) return;
    otherGoodMovesRequestKey = requestKey;
    if (otherGoodMovesController) otherGoodMovesController.abort();

    const cached = otherGoodMovesCache.get(requestKey);
    if (cached) {
        renderOtherGoodMovesState({ data: cached, count, fenComplete });
        return;
    }

    if (Date.now() < otherGoodMovesRetryAfter) {
        renderOtherGoodMovesState({ status: 'Lichess temporarily rate-limited requests. Try again after about one minute.', count, fenComplete });
        return;
    }
    const controller = new AbortController();
    otherGoodMovesController = controller;
    renderOtherGoodMovesState({ status: 'Loading alternative moves…', count, fenComplete });
    const url = `https://lichess.org/api/cloud-eval?fen=${encodeURIComponent(fen)}&multiPv=${count + 1}`;
    try {
        // Lichess recommends a single outstanding API request and a full-minute pause after HTTP 429.
        const response = await fetch(url, { signal: controller.signal, headers: { Accept: 'application/json' } });
        if (response.status === 429) {
            otherGoodMovesRetryAfter = Date.now() + 60000;
            throw new Error('Lichess rate limit reached. Wait about one minute before requesting alternatives again.');
        }
        const data = response.ok ? await response.json() : null;
        if (controller.signal.aborted || otherGoodMovesCurrentFen !== fen || otherGoodMovesRequestKey !== requestKey) return;
        const result = data && Array.isArray(data.pvs) ? data : null;
        otherGoodMovesCache.set(requestKey, result || { pvs: [], depth: 0 });
        if (otherGoodMovesCache.size > 180) otherGoodMovesCache.delete(otherGoodMovesCache.keys().next().value);
        if (result) {
            renderOtherGoodMovesState({ data: result, count, fenComplete });
        } else {
            renderOtherGoodMovesState({ status: response.status === 404 ? 'No cached alternatives are available for this position.' : `Lichess Cloud Eval returned HTTP ${response.status}.`, count, fenComplete });
        }
    } catch (error) {
        if (error?.name === 'AbortError' || controller.signal.aborted) return;
        if (otherGoodMovesCurrentFen === fen && otherGoodMovesRequestKey === requestKey) {
            renderOtherGoodMovesState({ status: error?.message || 'Could not load alternative moves. Check your connection and try again.', count, fenComplete });
        }
    } finally {
        if (otherGoodMovesController === controller) otherGoodMovesController = null;
    }
}

function refreshOtherGoodMoves() {
    otherGoodMovesRequestKey = '';
    const fen = getFEN();
    const count = Math.max(1, Math.min(4, Number.parseInt(window.chessHelper?.otherGoodMoves?.count, 10) || 2));
    if (fen) {
        otherGoodMovesCache.delete(`${fen}|${count}`);
        loadOtherGoodMoves(fen);
    } else {
        renderOtherGoodMovesState({ count });
    }
}

async function fetchEngineBestMove(fen, depth, signal = null) {
    const provider = getEngineProvider();
    const cacheKey = `${provider}|${fen}|${depth}`;
    if (fenCache.has(cacheKey)) {
        const cachedAnalysis = engineAnalysisCache.get(fen);
        if (cachedAnalysis) handleSuperModeEngineAnalysis(fen, cachedAnalysis);
        return fenCache.get(cacheKey);
    }
    if (engineInFlight.has(cacheKey)) return engineInFlight.get(cacheKey);
    const request = (async () => {
        if (provider === 'wasm') {
            return await fetchLocalWasmBestMove(fen, depth, signal, cacheKey);
        }
        if (provider === 'mujahi') {
            const adapter = getMujahiProvider();
            if (!adapter) throw new Error('MUJAHI provider adapter is not loaded.');
            const move = await adapter.fetchBestMove(fen, depth, signal, (analysis) => {
                const prior = engineAnalysisCache.get(fen);
                if (!prior || analysis.depth >= (prior.depth || 0)) {
                    setBoundedCache(engineAnalysisCache, fen, analysis, 120);
                    handleSuperModeEngineAnalysis(fen, analysis);
                }
                if (analysis.move) {
                    setBoundedCache(fenCache, `mujahi|${fen}|${analysis.depth}`, analysis.move);
                }
            });
            if (move) setBoundedCache(fenCache, cacheKey, move);
            return move;
        }
        const url = `https://stockfish.online/api/s/v2.php?fen=${encodeURIComponent(fen)}&depth=${depth}`;
        const data = await fetchJsonWithRetry(url, signal ? { signal } : {}, `Stockfish API depth ${depth}`);
        if (data === false) return false;
        if (data?.success && data.bestmove) {
            const move = data.bestmove.split(' ')[1];
            if (move) {
                const rawEval = data.evaluation ?? data.eval ?? data.score;
                const evaluation = rawEval === null || rawEval === undefined || rawEval === '' ? null : Number(rawEval);
                const rawMate = data.mate;
                const mate = rawMate === null || rawMate === undefined || rawMate === '' || rawMate === 'null' ? null : Number(rawMate);
                const analysis = {
                    move,
                    evaluation: Number.isFinite(evaluation) ? evaluation : null,
                    mate: Number.isFinite(mate) ? mate : null,
                    continuation: typeof data.continuation === 'string' ? data.continuation : '',
                    depth: Number(data.depth) || Number(depth) || 0,
                    raw: data
                };
                setBoundedCache(fenCache, cacheKey, move);
                const prior = engineAnalysisCache.get(fen);
                if (!prior || analysis.depth >= prior.depth) {
                    engineAnalysisCache.set(fen, analysis);
                    setBoundedCache(engineAnalysisCache, fen, analysis, 120);
                    handleSuperModeEngineAnalysis(fen, analysis);
                }
                return move;
            }
        }
        return null;
    })();
    engineInFlight.set(cacheKey, request);
    try { return await request; } finally { if (engineInFlight.get(cacheKey) === request) engineInFlight.delete(cacheKey); }
}

function fenToPieceBoard(fen) {
    const placement = (fen || '').split(' ')[0];
    const rows = placement.split('/');
    if (rows.length !== 8) return null;
    const board = Array(64).fill(null); // rank 1 starts at index 0
    for (let row = 0; row < 8; row++) {
        let file = 0;
        for (const ch of rows[row]) {
            if (/^[1-8]$/.test(ch)) { file += Number(ch); continue; }
            if (!/[pnbrqkPNBRQK]/.test(ch) || file > 7) return null;
            const rank = 7 - row;
            board[rank * 8 + file] = { type: ch.toLowerCase(), color: ch === ch.toUpperCase() ? 'w' : 'b', square: `${'abcdefgh'[file]}${rank + 1}` };
            file++;
        }
        if (file !== 8) return null;
    }
    return board;
}
function attackersOf(board, targetIndex, color) {
    const tf = targetIndex % 8, tr = Math.floor(targetIndex / 8), found = [];
    for (let i = 0; i < 64; i++) {
        const piece = board[i];
        if (!piece || piece.color !== color || i === targetIndex) continue;
        const ff = i % 8, fr = Math.floor(i / 8);
        const dx = tf - ff, dy = tr - fr, ax = Math.abs(dx), ay = Math.abs(dy);
        let attacks = false;
        if (piece.type === 'p') attacks = ax === 1 && dy === (color === 'w' ? 1 : -1);
        else if (piece.type === 'n') attacks = (ax === 1 && ay === 2) || (ax === 2 && ay === 1);
        else if (piece.type === 'k') attacks = Math.max(ax, ay) === 1;
        else {
            const diagonal = ax === ay && ax > 0;
            const straight = (dx === 0) !== (dy === 0);
            const canLine = piece.type === 'q' ? (diagonal || straight) : piece.type === 'b' ? diagonal : piece.type === 'r' ? straight : false;
            if (canLine) {
                const sx = Math.sign(dx), sy = Math.sign(dy);
                let x = ff + sx, y = fr + sy, clear = true;
                while (x !== tf || y !== tr) {
                    if (board[y * 8 + x]) { clear = false; break; }
                    x += sx; y += sy;
                }
                attacks = clear;
            }
        }
        if (attacks) found.push(piece);
    }
    return found;
}
function summarizeSuperModePosition(fen) {
    const board = fenToPieceBoard(fen);
    if (!board) return null;
    const counts = { w: { p:0,n:0,b:0,r:0,q:0,k:0 }, b: { p:0,n:0,b:0,r:0,q:0,k:0 } };
    const material = { w:0, b:0 };
    for (const piece of board) if (piece) { counts[piece.color][piece.type]++; material[piece.color] += SUPER_PIECE_VALUES[piece.type]; }
    const captured = { w: {}, b: {}, wValue: 0, bValue: 0 };
    for (const color of ['w','b']) for (const type of Object.keys(SUPER_START_COUNTS)) {
        const missing = Math.max(0, SUPER_START_COUNTS[type] - counts[color][type]);
        captured[color][type] = missing;
        captured[color === 'w' ? 'wValue' : 'bValue'] += missing * SUPER_PIECE_VALUES[type];
    }
    const myColor = getMyColor();
    const enemyColor = myColor === 'w' ? 'b' : 'w';
    const attacked = [], hanging = [];
    for (let i = 0; i < 64; i++) {
        const piece = board[i];
        if (!piece || piece.color !== myColor || piece.type === 'k') continue;
        const attackers = attackersOf(board, i, enemyColor);
        if (!attackers.length) continue;
        const defenders = attackersOf(board, i, myColor);
        const entry = { square: piece.square, type: piece.type, value: SUPER_PIECE_VALUES[piece.type], attackers: attackers.length, defenders: defenders.length };
        attacked.push(entry);
        if (!defenders.length) hanging.push(entry);
    }
    const centerSquares = [3 + 3*8, 4 + 3*8, 3 + 4*8, 4 + 4*8];
    const centerControlledSquares = centerSquares.filter(i => attackersOf(board, i, myColor).length > 0).map(i => `${'abcdefgh'[i % 8]}${Math.floor(i / 8) + 1}`);
    const centerControl = centerControlledSquares.length;
    const originalMinorSquares = myColor === 'w' ? ['b1','g1','c1','f1'] : ['b8','g8','c8','f8'];
    let homeMinorCount = 0;
    for (const sq of originalMinorSquares) {
        const file = 'abcdefgh'.indexOf(sq[0]), rank = Number(sq[1]) - 1;
        const piece = board[rank * 8 + file];
        if (piece && piece.color === myColor && ['n','b'].includes(piece.type)) homeMinorCount++;
    }
    const remainingMinor = board.filter(piece => piece && piece.color === myColor && ['n','b'].includes(piece.type)).length;
    const developedMinor = Math.max(0, remainingMinor - homeMinorCount);
    return { board, counts, material, captured, attacked, hanging, centerControl, centerControlledSquares, developedMinor, myColor };
}
function fmtEval(value) { return `${value > 0 ? '+' : ''}${value.toFixed(2)}`; }
function detectLastMoveSquares(previousFen, currentFen) {
    const before = fenToPieceBoard(previousFen), after = fenToPieceBoard(currentFen);
    if (!before || !after) return null;
    const changed = [];
    for (let i = 0; i < 64; i++) {
        const a = before[i], b = after[i];
        if ((a?.color || '') !== (b?.color || '') || (a?.type || '') !== (b?.type || '')) changed.push(i);
    }
    const kingFrom = changed.find(i => before[i]?.type === 'k' && !after[i]);
    const kingTo = changed.find(i => after[i]?.type === 'k' && !before[i]);
    if (kingFrom !== undefined && kingTo !== undefined) return { from: before[kingFrom].square, to: after[kingTo].square, mover: before[kingFrom].color };
    const destinations = changed.filter(i => after[i] && (!before[i] || before[i].color !== after[i].color || before[i].type !== after[i].type));
    if (!destinations.length) return null;
    const toIndex = destinations[0];
    const mover = after[toIndex].color;
    const sources = changed.filter(i => before[i]?.color === mover && (!after[i] || after[i].color !== mover || after[i].type !== before[i].type));
    const fromIndex = sources.find(i => before[i]?.type === after[toIndex]?.type) ?? sources[0];
    if (fromIndex === undefined) return { from: null, to: after[toIndex].square, mover };
    return { from: before[fromIndex].square, to: after[toIndex].square, mover };
}

function superModeGetOverlay(board) {
    if (!board) return null;
    if (superModeOverlayBoard !== board || !superModeBoardOverlay?.isConnected) {
        superModeClearBoardOverlay();

        overlay.className = 'ch-super-board-overlay';
        overlay.setAttribute('aria-hidden', 'true');

        superModeBoardOverlay = overlay;
        superModeOverlayBoard = board;
    }

}
function superModeSquarePosition(square, flipped) {
    const file = 'abcdefgh'.indexOf(square?.[0]);
    const rank = Number(square?.[1]);
    if (file < 0 || rank < 1 || rank > 8) return null;
    return { x: flipped ? 7 - file : file, y: flipped ? rank - 1 : 8 - rank };
}

function renderSuperModeBoard(fen = superModeCurrentFen) {
    const cfg = getSuperModeConfig();
    if (!cfg.enabled || !fen || !Object.values(cfg.features).some(Boolean)) {
        superModeClearBoardOverlay();
        return;
    }
    const boardEl = getBoard();
    if (!boardEl) return;
    const f = cfg.features;
    const flipped = boardEl.classList.contains('flipped');
    const activeAnalysis = superModeLatestAnalysis && superModeLatestAnalysis.fen === fen ? superModeLatestAnalysis : null;
    const displayedAnalysis = activeAnalysis || superModeLatestAnalysis;
    const moveEvent = superModeMoveEvent && superModeMoveEvent.fen === fen ? superModeMoveEvent : null;
    const opponentMove = superModeOpponentBestMove && superModeOpponentBestMove.fen === fen && (fen.split(' ')[1] || 'w') !== getMyColor() ? superModeOpponentBestMove : null;
    const renderKey = JSON.stringify({
        fen, flipped, features: f,
        eval: displayedAnalysis ? [displayedAnalysis.evaluation, displayedAnalysis.mate, displayedAnalysis.depth] : (superModeLastEval ? [superModeLastEval.evaluation, superModeLastEval.depth] : null),
        moveQuality: superModeMoveQuality,
        moveEvent, opponentMove: opponentMove?.move || '',
        alternatives: superModeApiData.alternatives?.pvs?.[1]?.moves || superModeApiData.alternatives?.message || '',
        opening: superModeApiData.opening?.moves?.[0]?.uci || superModeApiData.opening?.message || '',
        tablebase: [superModeApiData.tablebase?.category, superModeApiData.tablebase?.dtz, superModeApiData.tablebase?.message],
        review: superModeSessionReview
    });
    if (superModeOverlayBoard === boardEl && superModeBoardOverlay?.isConnected && superModeOverlayRenderKey === renderKey) return;
    const local = summarizeSuperModePosition(fen);
    if (!local) return;
    const overlay = superModeGetOverlay(boardEl);
    if (!overlay) return;
    overlay.replaceChildren();
    superModeOverlayRenderKey = renderKey;
    const hud = document.createElement('div');
    hud.className = 'ch-sm-board-hud';

    if (f.hanging) for (const piece of local.hanging) addSuperSquareMark(overlay, piece.square, flipped, 'is-hanging', '!');
    if (f.threats) {
        const already = new Set(f.hanging ? local.hanging.map(piece => piece.square) : []);
        for (const piece of local.attacked) if (!already.has(piece.square)) addSuperSquareMark(overlay, piece.square, flipped, 'is-attacked', '×');
    }
    if (f.activity) for (const square of local.centerControlledSquares) addSuperSquareMark(overlay, square, flipped, 'is-center', '');

    if (f.material) {
        const diff = local.material[local.myColor] - local.material[local.myColor === 'w' ? 'b' : 'w'];
        if (diff !== 0) addSuperHud(hud, `${diff > 0 ? 'YOU' : 'OPP'} +${Math.abs(diff)} MATERIAL`, diff > 0 ? 'is-positive' : 'is-negative');
    }
    if (f.captured) {
        const w = local.captured.wValue, b = local.captured.bValue;
        if (w + b > 0) addSuperHud(hud, `LOST W${w} · B${b}`, 'is-muted');
    }
    if (f.evaluation) {
        // Keep the evaluation rail mounted while a new position is being analysed.
        // Retain the last known score instead of removing/recreating the bar between FENs.
        const evalSource = displayedAnalysis && Number.isFinite(displayedAnalysis.evaluation)
            ? displayedAnalysis
            : superModeLastEval;
        const evalValue = Number.isFinite(evalSource?.evaluation) ? evalSource.evaluation : null;
        addSuperHud(hud, evalValue === null ? 'EVAL —' : `EVAL ${fmtEval(evalValue)} · D${evalSource?.depth || '—'}`, 'is-eval');
        const whitePct = evalValue === null ? 50 : Math.max(4, Math.min(96, 50 + evalValue * 8));
        const track = document.createElement('div');
        track.className = 'ch-sm-eval-track';
        const fill = document.createElement('div');
        fill.className = 'ch-sm-eval-fill';
        fill.style.height = `${whitePct}%`;
        track.appendChild(fill);
        overlay.appendChild(track);
    }
    if (f.mate) {
        const a = superModeLatestAnalysis;
        if (a && a.fen === fen && a.mate !== null) addSuperHud(hud, `MATE ${Math.abs(a.mate)}`, 'is-mate');
    }
    if (f.moveQuality && superModeMoveQuality) {
        const qualityMatch = superModeMoveQuality.match(/^(Blunder|Mistake|Inaccuracy|Strong move) estimate · eval (loss|gain) ([0-9.]+)/i);
        const shortQuality = qualityMatch ? `${qualityMatch[1].toUpperCase()} · ${qualityMatch[2].toUpperCase()} ${qualityMatch[3]}` : (superModeMoveQuality.startsWith('Small evaluation change') ? `MOVE ${superModeMoveQuality.match(/[+-][0-9.]+/)?.[0] || 'UPDATED'}` : superModeMoveQuality);
        addSuperHud(hud, shortQuality, /blunder|mistake/i.test(shortQuality) ? 'is-warning' : '');
    }

    if (f.blunders && moveEvent?.kind === 'blunder') {
        const moverLabel = moveEvent.mover === getMyColor() ? 'YOUR BLUNDER' : 'OPPONENT BLUNDER';
        addSuperHud(hud, `${moverLabel} · −${moveEvent.loss.toFixed(2)}`, 'is-warning');
        if (moveEvent.from) addSuperSquareMark(overlay, moveEvent.from, flipped, 'is-blunder-from', '');
        if (moveEvent.to) addSuperSquareMark(overlay, moveEvent.to, flipped, 'is-blunder-to', '!');
    }
    if (f.evalDrop && moveEvent?.kind === 'drop') {
        const moverLabel = moveEvent.mover === getMyColor() ? 'YOUR MOVE' : 'OPP MOVE';
        // Deliberately text-only: evaluation drops do not draw an arrow or move line.
        addSuperHud(hud, `${moverLabel} · EVAL DROP −${moveEvent.loss.toFixed(2)}`, 'is-eval-drop');
    }
    if (f.opponentBestMove && opponentMove) {
        addSuperHud(hud, `OPPONENT BEST · ${opponentMove.move.slice(0,2)}→${opponentMove.move.slice(2,4)}`, 'is-opponent-best');
        addSuperOpponentArrow(overlay, opponentMove.move, flipped);
    }

    if (f.alternatives) {
        const alt = superModeApiData.alternatives;
        const line = alt?.pvs?.[1]?.moves;
        if (line) addSuperHud(hud, `ALT ${line.split(' ').slice(0, 3).join(' ')}`, 'is-lookup');
    }
    if (f.openingExplorer) {
        const opening = superModeApiData.opening;
        const first = opening?.moves?.[0];
        if (first) {
            const games = (first.white || 0) + (first.draws || 0) + (first.black || 0);
            addSuperHud(hud, `BOOK ${first.san || first.uci || '?'} · ${games.toLocaleString()} games`, 'is-lookup');
        }
    }
    if (f.tablebase) {
        const tb = superModeApiData.tablebase;
        if (tb?.category) addSuperHud(hud, `TABLEBASE ${String(tb.category).toUpperCase()} · DTZ ${tb.dtz ?? '—'}`, 'is-lookup');
        
    }
    if (f.review && superModeSessionReview) addSuperHud(hud, superModeSessionReview, 'is-review');
    if (hud.childElementCount) overlay.appendChild(hud);
}
function updateSuperModeLocal(fen) {
    superModeCurrentFen = fen;
    const cfg = getSuperModeConfig();
    if (!cfg.enabled) { superModeClearBoardOverlay(); if (superModeAuxController) superModeAuxController.abort(); superModeAuxKey = ''; return; }
    renderSuperModeBoard(fen);
    // Run optional network lookups only on the user's turn to limit API traffic.
    if ((fen.split(' ')[1] || 'w') !== getMyColor()) {
        if (superModeAuxController) superModeAuxController.abort();
        superModeAuxController = null;
        superModeAuxKey = '';
        return;
    }
    loadSuperModeApis(fen);
}
function handleSuperModeEngineAnalysis(fen, analysis) {
    if (getFEN() !== fen) return;
    // Keep a tiny in-memory evaluation trail from normal engine results. This adds no API calls
    // and allows Post-game review to be enabled after a game has started.
    const priorSessionIndex = superModeSession.findIndex(item => item.fen === fen);
    const sessionItem = { fen, evaluation: analysis.evaluation, mate: analysis.mate, depth: analysis.depth, at: Date.now() };
    if (priorSessionIndex >= 0) {
        if ((analysis.depth || 0) >= (superModeSession[priorSessionIndex].depth || 0)) superModeSession[priorSessionIndex] = sessionItem;
    } else {
        superModeSession.push(sessionItem);
        if (superModeSession.length > 120) superModeSession.shift();
    }
    const cfg = getSuperModeConfig();
    if (!cfg.enabled) return;
    if (analysis.evaluation !== null && Number.isFinite(analysis.evaluation)) {
        const previous = superModeLastEval;
        if (previous && previous.fen !== fen && Number.isFinite(previous.evaluation)) {
            const active = (fen.split(' ')[1] || 'w');
            const lastMover = active === 'w' ? 'b' : 'w';
            const gain = lastMover === 'w' ? analysis.evaluation - previous.evaluation : previous.evaluation - analysis.evaluation;
            const loss = -gain;
            const moveSquares = detectLastMoveSquares(previous.fen, fen);
            superModeMoveEvent = loss >= 0.35 ? {
                fen, kind: loss >= 1.5 ? 'blunder' : 'drop', loss, mover: moveSquares?.mover || lastMover,
                from: moveSquares?.from || null, to: moveSquares?.to || null
            } : null;
            if (loss >= 1.5) superModeMoveQuality = `Blunder estimate · eval loss ${loss.toFixed(2)}`;
            else if (loss >= 0.8) superModeMoveQuality = `Mistake estimate · eval loss ${loss.toFixed(2)}`;
            else if (loss >= 0.35) superModeMoveQuality = `Inaccuracy estimate · eval loss ${loss.toFixed(2)}`;
            else if (gain >= 0.35) superModeMoveQuality = `Strong move estimate · eval gain ${gain.toFixed(2)}`;
            else superModeMoveQuality = `Small evaluation change · ${gain >= 0 ? '+' : ''}${gain.toFixed(2)} from the last observed position`;
        }
        superModeLastEval = { fen, evaluation: analysis.evaluation, depth: analysis.depth };
    }
    superModeLatestAnalysis = { ...analysis, fen };
    renderSuperModeBoard(fen);
}
function requestSuperModeOpponentBestMove(fen) {
    const cfg = getSuperModeConfig();
    const features = cfg.features || {};
    const needsOpponentAnalysis = !!(features.opponentBestMove || features.evaluation || features.mate || features.moveQuality || features.blunders || features.evalDrop);
    if (!cfg.enabled || !needsOpponentAnalysis || (fen.split(' ')[1] || 'w') === getMyColor()) return;
    if (superModeOpponentBestMove?.fen === fen || superModeOpponentRequestFen === fen) return;
    superModeOpponentRequestFen = fen;
    const controller = activeAnalysisController || (activeAnalysisController = new AbortController());
    const arrows = window.chessHelper?.arrows || {};
    const visibleDepths = ['d5','d10','d15'].filter(key => arrows[key]?.show).map(key => Number(arrows[key]?.depth) || 0);
    const fallbackDepth = Number(arrows.d10?.depth) || 10;
    const depth = Math.max(1, Math.min(20, Math.max(0, ...visibleDepths) || fallbackDepth));
    fetchEngineBestMove(fen, depth, controller.signal).then(move => {
        const currentFeatures = getSuperModeConfig().features || {};
        const stillNeeded = currentFeatures.opponentBestMove || currentFeatures.evaluation || currentFeatures.mate || currentFeatures.moveQuality || currentFeatures.blunders || currentFeatures.evalDrop;
        if (!move || controller.signal.aborted || getFEN() !== fen || !stillNeeded) return;
        superModeOpponentBestMove = { fen, move, depth: engineAnalysisCache.get(fen)?.depth || depth };
        renderSuperModeBoard(fen);
    }).catch(error => {
        if (error?.name !== 'AbortError') console.warn('[ChessHelper] Opponent best-move analysis failed', error);
    }).finally(() => {
        if (superModeOpponentRequestFen === fen) superModeOpponentRequestFen = '';
    });
}
function countFenPieces(fen) { return (fen.split(' ')[0].match(/[pnbrqk]/gi) || []).length; }
async function loadSuperModeApis(fen) {
    const cfg = getSuperModeConfig(), f = cfg.features;
    if (!cfg.enabled) return;
    const wants = ['openingExplorer','alternatives','tablebase'].filter(key => f[key]);
    if (!wants.length) { if (superModeAuxController) superModeAuxController.abort(); superModeAuxController = null; superModeAuxKey = ''; return; }
    const key = `${fen}|${wants.join(',')}`;
    if (key === superModeAuxKey) return;
    if (superModeAuxController) superModeAuxController.abort();
    superModeAuxController = new AbortController();
    const signal = superModeAuxController.signal;
    superModeAuxKey = key;
    for (const feature of wants) {
        const target = feature === 'openingExplorer' ? 'opening' : feature === 'tablebase' ? 'tablebase' : 'alternatives';
        superModeApiData[target] = superModeAuxCache.has(`${feature}|${fen}`)
            ? superModeAuxCache.get(`${feature}|${fen}`)
            : { message: 'Loading…' };
    }
    renderSuperModeBoard(fen);
    const current = () => !signal.aborted && getFEN() === fen && getSuperModeConfig().enabled;
    const tasks = [];
    if (f.openingExplorer && !superModeAuxCache.has(`openingExplorer|${fen}`)) tasks.push((async () => {
        const url = `https://explorer.lichess.org/lichess?fen=${encodeURIComponent(fen)}&moves=5&topGames=0&recentGames=0`;
        const data = await fetchJsonWithRetry(url, { signal, headers: { 'Accept':'application/json' } }, 'SuperMode Opening Explorer');
        if (!current()) return;
        const value = data && data !== false ? data : { message: data === false ? 'API access denied or unavailable.' : 'No opening data found for this position.' };
        setBoundedCache(superModeAuxCache, `openingExplorer|${fen}`, value, 300); superModeApiData.opening = value; renderSuperModeBoard(fen);
    })());
    if (f.alternatives && !superModeAuxCache.has(`alternatives|${fen}`)) tasks.push((async () => {
        const url = `https://lichess.org/api/cloud-eval?fen=${encodeURIComponent(fen)}&multiPv=3`;
        const data = await fetchJsonWithRetry(url, { signal, headers: { 'Accept':'application/json' } }, 'SuperMode Alternative Lines');
        if (!current()) return;
        const value = data && data !== false && Array.isArray(data.pvs) ? data : { message: data === false ? 'Cloud evaluation unavailable or not cached.' : 'No cached alternative lines for this position.' };
        setBoundedCache(superModeAuxCache, `alternatives|${fen}`, value, 300); superModeApiData.alternatives = value; renderSuperModeBoard(fen);
    })());
    if (f.tablebase && !superModeAuxCache.has(`tablebase|${fen}`)) tasks.push((async () => {
        if (countFenPieces(fen) > 7) {
            const value = { message: 'Not eligible yet: tablebase supports positions with seven or fewer pieces.' };
            setBoundedCache(superModeAuxCache, `tablebase|${fen}`, value, 300); superModeApiData.tablebase = value; renderSuperModeBoard(fen); return;
        }
        const url = `https://tablebase.lichess.ovh/standard?fen=${encodeURIComponent(fen)}`;
        const data = await fetchJsonWithRetry(url, { signal, headers: { 'Accept':'application/json' } }, 'SuperMode Endgame Tablebase');
        if (!current()) return;
        const value = data && data !== false ? data : { message: data === false ? 'Tablebase lookup unavailable.' : 'No tablebase result found.' };
        setBoundedCache(superModeAuxCache, `tablebase|${fen}`, value, 300); superModeApiData.tablebase = value; renderSuperModeBoard(fen);
    })());
    Promise.allSettled(tasks).then(() => { if (current()) renderSuperModeBoard(fen); });
}
function reviewSuperModeSession() {
    if (!superModeSession.length) { superModeSessionReview = 'No engine-evaluated positions have been recorded yet.'; renderSuperModeBoard(superModeCurrentFen); return; }
    const scored = superModeSession.filter(x => Number.isFinite(x.evaluation));
    if (scored.length < 2) { superModeSessionReview = `${superModeSession.length} positions recorded, but at least two evaluations are needed for a review.`; renderSuperModeBoard(superModeCurrentFen); return; }
    let largest = { swing: 0, from: null, to: null };
    for (let i = 1; i < scored.length; i++) {
        const swing = Math.abs(scored[i].evaluation - scored[i-1].evaluation);
        if (swing > largest.swing) largest = { swing, from: scored[i-1], to: scored[i] };
    }
    superModeSessionReview = `${scored.length} evaluated positions reviewed. Largest evaluation swing: ${largest.swing.toFixed(2)} (${fmtEval(largest.from.evaluation)} → ${fmtEval(largest.to.evaluation)}). This is a session summary, not a complete PGN-level game review.`;
    renderSuperModeBoard(superModeCurrentFen);
}
function refreshSuperMode() {
    const cfg = getSuperModeConfig();
    if (!cfg.enabled) {
        superModeClearBoardOverlay();
        if (superModeAuxController) superModeAuxController.abort();
        superModeAuxController = null; superModeAuxKey = '';
    } else {
        superModeAuxKey = '';
        const fen = getFEN();
        if (fen) {
            updateSuperModeLocal(fen);
            const cached = engineAnalysisCache.get(fen);
            if (cached) handleSuperModeEngineAnalysis(fen, cached);
            const features = cfg.features || {};
            const needsOpponentAnalysis = features.opponentBestMove || features.evaluation || features.mate || features.moveQuality || features.blunders || features.evalDrop;
            if (needsOpponentAnalysis && (fen.split(' ')[1] || 'w') !== getMyColor() && window.chessHelper?.useEngine !== false) requestSuperModeOpponentBestMove(fen);
        }
    }
    renderSuperModeBoard(superModeCurrentFen);
}

function dispatchPointer(type, elem, coords) { elem.dispatchEvent(new PointerEvent(type, { bubbles: true, cancelable: true, view: window, clientX: coords.x, clientY: coords.y, buttons: 1, pointerId: 1, isPrimary: true, width: 1, height: 1, pressure: 0.5 })); }

async function makeMove(move) {
    if (!move) return;
    const board = getBoard();
    if (!board) return;
    const fromSq = move.substring(0, 2);
    if (!isMyPieceOnSquare(fromSq)) return;

}

    if (document.hidden) return;

        if (activeAnalysisController) activeAnalysisController.abort();
        mujahiProvider?.cancelAll();

    loadOtherGoodMoves(fen);

    if (fen !== lastObservedFen) {
        lastObservedFen = fen;
        if (activeAnalysisController) activeAnalysisController.abort();
        activeAnalysisController = new AbortController();
        mujahiProvider?.setActivePosition(fen);
        activeAnalysisFen = '';
        if (retryTimer) { clearTimeout(retryTimer); retryTimer = null; }
    }

    const activeColor = fen.split(' ')[1], myColor = getMyColor();
    if (activeColor !== myColor) {
        lastProcessedFen = '';
        activeAnalysisFen = '';
        if (window.clearAllArrows) window.clearAllArrows();
        const turnCfg = window.chessHelper || {};
        const turnFeatures = turnCfg.superModeFeatures || {};
        const needsOpponentAnalysis = turnFeatures.opponentBestMove || turnFeatures.evaluation || turnFeatures.mate || turnFeatures.moveQuality || turnFeatures.blunders || turnFeatures.evalDrop;
        if (turnCfg.superModeEnabled && needsOpponentAnalysis && turnCfg.useEngine !== false) requestSuperModeOpponentBestMove(fen);
        return;
    }
    if (fen === lastProcessedFen || fen === activeAnalysisFen) return;
    if (lastUsageRecordedFen !== fen && !checkFreemiumLimit()) return;

    const cfg = window.chessHelper || {};
    const arrows = cfg.arrows || {};
    const engineEnabled = cfg.useEngine !== false;
    const engineKeys = engineEnabled ? ['d5','d10','d15'].filter(key => arrows[key]?.show) : [];
    const superFeatures = cfg.superModeFeatures || {};
    const superNeedsEngineEval = !!cfg.superModeEnabled && !!(superFeatures.evaluation || superFeatures.mate || superFeatures.moveQuality || superFeatures.blunders || superFeatures.evalDrop);
    const addSuperEvalJob = engineEnabled && superNeedsEngineEval && engineKeys.length === 0;
    if (!engineKeys.length && !addSuperEvalJob) return;

    const controller = activeAnalysisController || (activeAnalysisController = new AbortController());
    const generation = ++analysisGeneration;
    activeAnalysisFen = fen;
    let autoplayKey = null;
    if (cfg.autoPlay) {
        const autoplaySource = cfg.autoplayArrow || 'd15';
        if (autoplaySource === 'random-blue-teal') {
            // Randomly choose from the Blue (D5) and Teal (D10) arrows that are enabled.
            // If only one is enabled, use that one; if neither is enabled, do not auto-play.
            const availableRandomSources = ['d5', 'd10'].filter(key => engineKeys.includes(key));
            if (availableRandomSources.length) {
                autoplayKey = availableRandomSources[randomIntInclusive(0, availableRandomSources.length - 1)];
            }
        } else if (['d5', 'd10', 'd15'].includes(autoplaySource)) {
            autoplayKey = autoplaySource;
        } else {
            autoplayKey = 'd15';
        }
    }
    const autoplayEpochAtStart = autoPlayEpoch;
    if (window.clearAllArrows) window.clearAllArrows();
    if (lastUsageRecordedFen !== fen) {
        lastUsageRecordedFen = fen;
        recordMoveUsage();
    }

    // Launch each enabled source independently. A slow depth never blocks a newer FEN.
    const jobs = engineKeys.map(key => ({ key, run: () => fetchEngineBestMove(fen, arrows[key].depth, controller.signal) }));
    if (addSuperEvalJob) jobs.push({ key: 'superEval', run: () => fetchEngineBestMove(fen, arrows.d10?.depth || 10, controller.signal) });
    let remaining = jobs.length;
    let anyFailed = false;
    let autoPlayed = false;

    const finishJob = () => {
        remaining--;
        if (remaining !== 0) return;
        if (generation !== analysisGeneration || controller.signal.aborted || document.hidden || getFEN() !== fen) return;
        activeAnalysisFen = '';
        if (!anyFailed) {
            // If auto-play was enabled/disabled while analysis was running, refresh this
            // position once so the current auto-play preference is honoured.
            if (window.chessHelper?.autoPlay && autoplayEpochAtStart !== autoPlayEpoch) {
                lastProcessedFen = '';
                scheduleTurnCheck();
            } else {
                lastProcessedFen = fen;
            }
        } else if (getEngineProvider() === 'wasm' && localEngineFailure) {
            // A missing/broken local build is a persistent setup error, not a transient
            // network failure. Avoid retrying every 900 ms until the user changes mode.
            lastProcessedFen = fen;
        } else {
            // Transient hosted API failures remain eligible for a short retry.
            lastProcessedFen = '';
            if (retryTimer) clearTimeout(retryTimer);
            retryTimer = setTimeout(() => {
                retryTimer = null;
                if (!document.hidden && getFEN() === fen) scheduleTurnCheck();
            }, 900);
        }
    };

    for (const job of jobs) {
        job.run().then(async move => {
            if (!move) { if (move !== false) anyFailed = true; return; }
            if (generation !== analysisGeneration || controller.signal.aborted || document.hidden || getFEN() !== fen) return;
            const arrowCfg = (window.chessHelper?.arrows || {})[job.key];
            if (!arrowCfg?.show || window.chessHelper?.useEngine === false) return;
            if (window.drawArrow) window.drawArrow(job.key, move);
            if (autoplayKey === job.key && !autoPlayed && window.chessHelper?.autoPlay) {
                autoPlayed = true;
                const randomizer = window.chessHelper?.autoplayRandomizer || {};
                const minDelay = Math.max(0, Math.min(10000, Number.isFinite(Number(randomizer.minMs)) ? Math.floor(Number(randomizer.minMs)) : 350));
                const maxDelay = Math.max(minDelay, Math.min(10000, Number.isFinite(Number(randomizer.maxMs)) ? Math.floor(Number(randomizer.maxMs)) : 1400));
                const delayMs = randomizer.enabled ? randomIntInclusive(minDelay, maxDelay) : 0;
                const delayCompleted = await waitForAutoPlayDelay(delayMs, controller.signal);

                await makeMove(move);
            }
        }).catch(e => {
            if (e?.name !== 'AbortError') console.error('[ChessEngine] Analysis task failed', e);
            anyFailed = true;
        }).finally(finishJob);
    }
}

    'use strict';
    const CHANNEL = 'chess-helper-local-stockfish-v1';
    const ALLOWED_PARENT_ORIGIN = 'https://www.chess.com';
    const ENGINE_URL = chrome.runtime.getURL('engine/stockfish-19-lite-single.js');

        window.parent.postMessage({ channel: CHANNEL, type, ...extra }, '*');
    }

        failed = true;
        const message = error?.message || String(error || 'Unknown Stockfish worker error');
        notify('error', { message });
    }

    function startWorker() {
        try {
            // This extension-origin page is the same origin as the packaged worker,
            // unlike the Chess.com content script that embeds this host.
            worker = new Worker(ENGINE_URL);
            worker.onmessage = event => {
                const line = typeof event.data === 'string' ? event.data : String(event.data ?? '');
                if (line) notify('line', { line });
            };
            worker.onerror = event => {
                fail(new Error(event.message || 'Unable to load Stockfish WASM worker. Check that the JS and WASM files are installed together.'));
                event.preventDefault?.();
            };
            worker.onmessageerror = () => fail(new Error('Could not decode a message from the Stockfish worker.'));
            notify('ready');
        } catch (error) {
            fail(error);
        }
    }

    window.addEventListener('message', event => {
        if (event.source !== window.parent || event.origin !== ALLOWED_PARENT_ORIGIN) return;
        const data = event.data;
        if (!data || data.channel !== CHANNEL) return;
        if (data.type === 'command') {
            if (failed || !worker) {
                notify('error', { message: 'Stockfish worker is not running. Check engine/stockfish-19-lite-single.js and its matching .wasm file.' });
                return;
            }
            const command = String(data.command || '').trim();
            // Accept only standard UCI commands used by Chess Helper.
            if (!/^(uci|isready|ucinewgame|stop|quit|position (?:fen .+|startpos(?: moves .*)?)|go depth \d+|setoption name [A-Za-z0-9 _]+ value \d+)$/.test(command)) return;
            worker.postMessage(command);
        } else if (data.type === 'terminate') {
            try { worker?.terminate(); } catch (_) {}
            worker = null;
            failed = false;
            notify('terminated');
        }
    });

    startWorker();
})();

/**
 * MUJAHI Chess Engine — Manifest V3 Background Service Worker
 *
 * Keeps MUJAHI backend requests inside the extension service worker (using MV3
 * host_permissions for https://mujahi-chess.onrender.com/*) so Chess.com pages
 * never need third-party CORS exemptions and SSE progressive streaming runs cleanly.
 */
'use strict';

const DEFAULT_MUJAHI_API_URL = 'https://mujahi-chess.onrender.com';

let workerSessionId = null;
function getSessionId() {
  if (!workerSessionId) {
    const id =
      typeof crypto !== 'undefined' && typeof crypto.randomUUID === 'function'
        ? crypto.randomUUID()
        : `${Date.now().toString(36)}-${Math.random().toString(36).slice(2, 10)}`;
    workerSessionId = `ext_${id}`;
  }
  return workerSessionId;
}

function normalizeBaseUrl(baseUrl) {
  const clean = typeof baseUrl === 'string' && baseUrl.trim() ? baseUrl.trim() : DEFAULT_MUJAHI_API_URL;
  return clean.replace(/\/+$/, '');
}

async function analyzeJson({ baseUrl, fen, depths, timeoutMs, clientSessionId, signal }) {
  const sessionId = clientSessionId || getSessionId();
  const url = `${normalizeBaseUrl(baseUrl)}/v1/analyze`;
  const res = await fetch(url, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Accept: 'application/json',
      'X-Client-Session-Id': sessionId,
    },
    body: JSON.stringify({
      fen,
      depths,
      clientSessionId: sessionId,
      ...(timeoutMs ? { timeoutMs } : {}),
    }),
    signal,
  });

  const payload = await res.json().catch(() => null);
  if (!res.ok) {
    throw new Error(payload?.error?.message || `HTTP ${res.status} from MUJAHI API`);
  }
  return payload;
}

async function analyzeStream({ baseUrl, fen, depths, timeoutMs, clientSessionId, signal, onEvent }) {
  const sessionId = clientSessionId || getSessionId();
  const url = `${normalizeBaseUrl(baseUrl)}/v1/analyze/stream`;
  const res = await fetch(url, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Accept: 'text/event-stream',
      'X-Client-Session-Id': sessionId,
    },
    body: JSON.stringify({
      fen,
      depths,
      clientSessionId: sessionId,
      ...(timeoutMs ? { timeoutMs } : {}),
    }),
    signal,
  });

  if (!res.ok) {
    const errPayload = await res.json().catch(() => null);
    throw new Error(errPayload?.error?.message || `HTTP ${res.status} from MUJAHI stream`);
  }

  if (!res.body) {
    throw new Error('ReadableStream unavailable in service worker.');
  }

  const reader = res.body.getReader();
  const decoder = new TextDecoder();
  let buffer = '';
  let sawTerminalEvent = false;

  const flushBlock = (block) => {
    let event = 'message';
    const dataLines = [];
    for (const line of block.split('\n')) {
      if (line.startsWith(':')) continue;
      if (line.startsWith('event:')) event = line.slice(6).trim();
      else if (line.startsWith('data:')) dataLines.push(line.slice(5).trim());
    }
    if (!dataLines.length) return;

    try {
      const data = JSON.parse(dataLines.join('\n'));
      if (event === 'complete' || event === 'error') {
        sawTerminalEvent = true;
      }
      onEvent(event, data);
    } catch {
      // Ignore malformed SSE comment/keepalive chunk
    }
  };

  while (true) {
    const { value, done } = await reader.read();
    if (done) break;
    buffer += decoder.decode(value, { stream: true }).replace(/\r\n/g, '\n');

    let splitIdx;
    while ((splitIdx = buffer.indexOf('\n\n')) !== -1) {
      const block = buffer.slice(0, splitIdx);
      buffer = buffer.slice(splitIdx + 2);
      if (block.trim()) flushBlock(block);
    }
  }

  buffer += decoder.decode().replace(/\r\n/g, '\n');
  if (buffer.trim()) {
    flushBlock(buffer);
  }

  if (!sawTerminalEvent && !signal?.aborted) {
    throw new Error('MUJAHI SSE stream closed unexpectedly.');
  }
}

// Long-lived port connection for progressive SSE depth snapshots (D5 -> D10 -> D15)
chrome.runtime.onConnect.addListener((port) => {
  if (port.name !== 'mujahi-analysis-stream') return;

  let activeController = null;
  let disconnected = false;

  const safePost = (msg) => {
    if (!disconnected) {
      try {
        port.postMessage(msg);
      } catch {
        disconnected = true;
      }
    }
  };

  port.onDisconnect.addListener(() => {
    disconnected = true;
    if (activeController) {
      activeController.abort();
      activeController = null;
    }
  });

  port.onMessage.addListener(async (msg) => {
    if (!msg || typeof msg !== 'object') return;

    if (msg.type === 'cancel') {
      if (activeController) {
        activeController.abort();
        activeController = null;
      }
      return;
    }

    if (msg.type === 'analyze_stream') {
      if (activeController) activeController.abort();
      const controller = new AbortController();
      activeController = controller;

      try {
        await analyzeStream({
          baseUrl: msg.baseUrl,
          fen: msg.fen,
          depths: msg.depths,
          timeoutMs: msg.timeoutMs,
          clientSessionId: msg.clientSessionId,
          signal: controller.signal,
          onEvent: (event, data) => {
            safePost({ type: 'sse_event', requestId: msg.requestId, event, data });
          },
        });
      } catch (err) {
        if (err?.name !== 'AbortError' && !disconnected) {
          safePost({
            type: 'sse_error',
            requestId: msg.requestId,
            message: err?.message || 'MUJAHI stream failed',
          });
        }
      } finally {
        if (activeController === controller) {
          activeController = null;
        }
      }
    }
  });
});

// One-shot JSON fallback & health probe
chrome.runtime.onMessage.addListener((msg, _sender, sendResponse) => {
  if (!msg || typeof msg !== 'object') return false;

  if (msg.type === 'MUJAHI_HEALTH') {

    fetch(`${baseUrl}/health`, { headers: { Accept: 'application/json' } })
      .then(async (res) => {
        const payload = await res.json().catch(() => null);
        sendResponse({ ok: res.ok, status: res.status, payload });
      })
      .catch((err) => {
        sendResponse({ ok: false, status: 0, error: err?.message || 'Health request failed' });
      });
    return true;
  }

  if (msg.type === 'MUJAHI_ANALYZE_JSON') {
    const controller = new AbortController();
    analyzeJson({
      baseUrl: msg.baseUrl,
      fen: msg.fen,
      depths: msg.depths,
      timeoutMs: msg.timeoutMs,
      clientSessionId: msg.clientSessionId,
      signal: controller.signal,
    })
      .then((payload) => sendResponse({ ok: true, payload }))
      .catch((err) => sendResponse({ ok: false, error: err?.message || 'MUJAHI JSON request failed' }));
    return true;
  }

  return false;
});

/**
 * MUJAHI Chess Engine — Provider Adapter for Chess Helper 2.1.0 (SuperMode)
 *
 * Preserves existing providers:
 *   - 'api'    (Hosted API — StockfishOnline default)
 *   - 'wasm'   (Local WASM — Stockfish 19 Lite worker)

 *   - 'mujahi' (MUJAHI Stockfish 19 API via MV3 background service worker)
 *
 * Returns normalized Chess Helper 2.1.0 analysis objects:
 *   { move, evaluation, mate, continuation, depth, raw }
 * where `evaluation` and `mate` are always normalized to White's point of view.
 */
(function attachMujahiExtensionAdapter(global) {
  'use strict';

  const DEFAULT_API_BASE_URL = 'https://mujahi-chess.onrender.com';

  function makeAbortError(message = 'Aborted') {
    if (typeof DOMException === 'function') {
      return new DOMException(message, 'AbortError');
    }
    const err = new Error(message);
    err.name = 'AbortError';
    return err;
  }

  /**
   * Normalizes a single MUJAHI depth snapshot or top-level response into
   * the exact shape expected by Chess Helper 2.1.0 `engineAnalysisCache`.
   */
  function normalizeMujahiSnapshot(snapshot, rawPayload = null) {
    if (!snapshot || !snapshot.bestmove) return null;
    const rawEval = snapshot.evaluation ?? snapshot.eval ?? snapshot.score;
    const evaluation =
      rawEval === null || rawEval === undefined || rawEval === '' ? null : Number(rawEval);
    const mate =
      snapshot.mate === null || snapshot.mate === undefined || snapshot.mate === '' || snapshot.mate === 'null'
        ? null
        : Number(snapshot.mate);

    return {
      move: String(snapshot.bestmove).trim(),
      evaluation: Number.isFinite(evaluation) ? evaluation : null,
      mate: Number.isFinite(mate) ? mate : null,
      continuation: typeof snapshot.continuation === 'string' ? snapshot.continuation : '',
      depth: Number(snapshot.depth) || 0,
      raw: rawPayload || snapshot,
    };
  }

  class MujahiExtensionProvider {
    constructor({
      baseUrl = DEFAULT_API_BASE_URL,
      clientSessionId = null,
      debounceMs = 25,
      useSseStream = true,
      timeoutMs = 45000,
    } = {}) {
      this.baseUrl = String(baseUrl || DEFAULT_API_BASE_URL).replace(/\/+$/, '');
      this.clientSessionId =
        clientSessionId ||
        `ext_${Date.now().toString(36)}_${Math.random().toString(36).slice(2, 8)}`;
      this.debounceMs = debounceMs;
      this.useSseStream = useSseStream;
      this.timeoutMs = timeoutMs;

      this.currentFen = '';
      this.batchTimers = new Map();
      this.activeStreams = new Map();
    }

    setActivePosition(fen) {
      if (this.currentFen && this.currentFen !== fen) {
        this.cancelAll();
      }
      this.currentFen = fen;
    }

    cancelAll() {
      for (const timer of this.batchTimers.values()) clearTimeout(timer);
      this.batchTimers.clear();
      for (const stream of this.activeStreams.values()) {
        stream.cancelled = true;
        try {
          stream.port?.postMessage({ type: 'cancel' });
          stream.port?.disconnect();
        } catch {
          // Ignore disconnected port errors
        }
        stream.rejectAll?.(makeAbortError('Superseded by newer FEN'));
      }
      this.activeStreams.clear();
    }

    /**
     * Batches simultaneous D5/D10/D15 calls from Chess Helper 2.1.0 for the same FEN
     * into ONE single-search Stockfish 19 request on the MUJAHI backend.
     *
     * @param {string} fen
     * @param {number} depth
     * @param {AbortSignal|null} signal
     * @param {(analysis: object) => void} [onNormalizedAnalysis]
     * @returns {Promise<string|null>} Best UCI move for requested depth
     */
    fetchBestMove(fen, depth, signal = null, onNormalizedAnalysis = null) {
      if (signal?.aborted) {
        return Promise.reject(makeAbortError('Aborted'));
      }

      this.currentFen = fen;
      const targetDepth = Number(depth);

      return new Promise((resolve, reject) => {
        let batch = this.activeStreams.get(fen);
        if (!batch) {
          batch = {
            fen,
            depths: new Set(),
            waiters: [],
            started: false,
            cancelled: false,
            port: null,
            resolvedSnapshots: new Map(),
            rejectAll: (err) => {
              for (const w of batch.waiters) {
                if (!w.settled) {
                  w.settled = true;
                  w.reject(err);
                }
              }
            },
          };
          this.activeStreams.set(fen, batch);
        }

        const waiter = {
          depth: targetDepth,
          settled: false,
          onNormalizedAnalysis,
          resolve,
          reject,
        };
        batch.depths.add(targetDepth);
        batch.waiters.push(waiter);

        if (signal) {
          signal.addEventListener(
            'abort',
            () => {
              if (!waiter.settled) {
                waiter.settled = true;
                waiter.reject(makeAbortError('Aborted'));
              }
              const allDone = batch.waiters.every((w) => w.settled);
              if (allDone) {
                batch.cancelled = true;
                const pendingTimer = this.batchTimers.get(fen);
                if (pendingTimer) {
                  clearTimeout(pendingTimer);
                  this.batchTimers.delete(fen);
                }
                try {
                  batch.port?.postMessage({ type: 'cancel' });
                  batch.port?.disconnect();
                } catch {
                  // Ignore
                }
                if (this.activeStreams.get(fen) === batch) {
                  this.activeStreams.delete(fen);
                }
              }
            },
            { once: true }
          );
        }

        // Already resolved in this shared batch
        if (batch.resolvedSnapshots.has(targetDepth)) {
          const snap = batch.resolvedSnapshots.get(targetDepth);
          waiter.settled = true;
          if (typeof waiter.onNormalizedAnalysis === 'function') {
            waiter.onNormalizedAnalysis(snap);
          }
          waiter.resolve(snap.move);
          return;
        }

        if (!batch.started && !this.batchTimers.has(fen)) {
          const timer = setTimeout(() => {
            this.batchTimers.delete(fen);
            this._executeBatch(batch);
          }, this.debounceMs);
          this.batchTimers.set(fen, timer);
        }
      });
    }

    _resolveDepthWaiters(batch, snapshot, rawPayload = null) {
      if (batch.cancelled || (this.currentFen && this.currentFen !== batch.fen)) {
        return; // Discard obsolete position result cleanly
      }
      const normalized = normalizeMujahiSnapshot(snapshot, rawPayload);
      if (!normalized) return;

      batch.resolvedSnapshots.set(normalized.depth, normalized);
      for (const waiter of batch.waiters) {
        if (!waiter.settled && waiter.depth === normalized.depth) {
          waiter.settled = true;
          if (typeof waiter.onNormalizedAnalysis === 'function') {
            waiter.onNormalizedAnalysis(normalized);
          }
          waiter.resolve(normalized.move);
        }
      }
    }

    _executeJsonFallback(batch, depths) {
      if (batch.cancelled || batch.waiters.every((w) => w.settled)) {
        if (this.activeStreams.get(batch.fen) === batch) this.activeStreams.delete(batch.fen);
        return;
      }

      if (typeof chrome !== 'undefined' && chrome.runtime && typeof chrome.runtime.sendMessage === 'function') {
        try {
          chrome.runtime.sendMessage(
            {
              type: 'MUJAHI_ANALYZE_JSON',
              baseUrl: this.baseUrl,
              fen: batch.fen,
              depths,
              timeoutMs: this.timeoutMs,
              clientSessionId: this.clientSessionId,
            },
            (response) => {
              const lastErr = chrome.runtime.lastError;
              if (batch.cancelled) {
                if (this.activeStreams.get(batch.fen) === batch) this.activeStreams.delete(batch.fen);
                return;
              }
              if (lastErr || !response?.ok) {
                batch.rejectAll(
                  new Error(lastErr?.message || response?.error || 'MUJAHI request failed')
                );
                if (this.activeStreams.get(batch.fen) === batch) this.activeStreams.delete(batch.fen);
                return;
              }
              const results = response.payload?.results || {};
              for (const d of depths) {
                if (results[String(d)]) {
                  this._resolveDepthWaiters(batch, results[String(d)], response.payload);
                }
              }
              for (const waiter of batch.waiters) {
                if (!waiter.settled) {
                  waiter.settled = true;
                  waiter.resolve(null);
                }
              }
              if (this.activeStreams.get(batch.fen) === batch) this.activeStreams.delete(batch.fen);
            }
          );
        } catch (err) {
          batch.rejectAll(err instanceof Error ? err : new Error(String(err || 'MUJAHI message bridge failed')));
          if (this.activeStreams.get(batch.fen) === batch) this.activeStreams.delete(batch.fen);
        }
        return;
      }

      batch.rejectAll(new Error('chrome.runtime MV3 bridge unavailable.'));
      if (this.activeStreams.get(batch.fen) === batch) this.activeStreams.delete(batch.fen);
    }

    _executeBatch(batch) {
      if (batch.cancelled || batch.waiters.every((w) => w.settled)) {
        if (this.activeStreams.get(batch.fen) === batch) this.activeStreams.delete(batch.fen);
        return;
      }

      batch.started = true;
      const depths = Array.from(batch.depths).sort((a, b) => a - b);

      if (typeof chrome !== 'undefined' && chrome.runtime && typeof chrome.runtime.connect === 'function' && this.useSseStream) {
        let port;
        try {
          port = chrome.runtime.connect({ name: 'mujahi-analysis-stream' });
        } catch {
          this._executeJsonFallback(batch, depths);
          return;
        }

        const requestId = `${Date.now()}_${Math.random().toString(36).slice(2, 8)}`;
        batch.port = port;
        let finishedCleanly = false;

        port.onDisconnect.addListener(() => {
          const runtimeErr = chrome.runtime.lastError;
          if (finishedCleanly || batch.cancelled || batch.waiters.every((w) => w.settled)) {
            if (this.activeStreams.get(batch.fen) === batch) this.activeStreams.delete(batch.fen);
            return;
          }
          // If MV3 service worker disconnected before any depth arrived, retry once over one-shot JSON
          if (batch.resolvedSnapshots.size === 0 && !runtimeErr) {
            this._executeJsonFallback(batch, depths);
            return;
          }
          batch.rejectAll(new Error(runtimeErr?.message || 'MUJAHI service worker stream disconnected.'));
          if (this.activeStreams.get(batch.fen) === batch) this.activeStreams.delete(batch.fen);
        });

        port.onMessage.addListener((msg) => {
          if (!msg || msg.requestId !== requestId) return;

          if (msg.type === 'sse_event') {
            if (msg.event === 'snapshot') {
              this._resolveDepthWaiters(batch, msg.data, msg.data);
            } else if (msg.event === 'complete') {
              finishedCleanly = true;
              const results = msg.data?.results || {};
              for (const d of depths) {
                if (results[String(d)]) {
                  this._resolveDepthWaiters(batch, results[String(d)], msg.data);
                }
              }
              for (const waiter of batch.waiters) {
                if (!waiter.settled) {
                  waiter.settled = true;
                  waiter.resolve(null);
                }
              }
              if (this.activeStreams.get(batch.fen) === batch) this.activeStreams.delete(batch.fen);
              try {
                port.disconnect();
              } catch {
                // Ignore
              }
            } else if (msg.event === 'error') {
              finishedCleanly = true;
              batch.rejectAll(new Error(msg.data?.error?.message || 'MUJAHI stream error'));
              if (this.activeStreams.get(batch.fen) === batch) this.activeStreams.delete(batch.fen);
              try {
                port.disconnect();
              } catch {
                // Ignore
              }
            }
          } else if (msg.type === 'sse_error') {
            finishedCleanly = true;
            batch.rejectAll(new Error(msg.message || 'MUJAHI stream failed'));
            if (this.activeStreams.get(batch.fen) === batch) this.activeStreams.delete(batch.fen);
            try {
              port.disconnect();
            } catch {
              // Ignore
            }
          }
        });

        try {
          port.postMessage({
            type: 'analyze_stream',
            requestId,
            baseUrl: this.baseUrl,
            fen: batch.fen,
            depths,
            timeoutMs: this.timeoutMs,
            clientSessionId: this.clientSessionId,
          });
        } catch {
          finishedCleanly = true;
          this._executeJsonFallback(batch, depths);
        }
        return;
      }

      this._executeJsonFallback(batch, depths);
    }
  }

  global.MujahiExtensionAdapter = {
    MujahiExtensionProvider,
    normalizeMujahiSnapshot,
  };
})(typeof window !== 'undefined' ? window : globalThis);

// --- DRAG LOGIC ---
function setupDragEvents() { const signal = uiAbortController?.signal; bubbleEl.addEventListener('mousedown', dragStart, { signal }); document.addEventListener('mouseup', dragEnd, { signal }); document.addEventListener('mousemove', dragMove, { signal, passive: true }); bubbleEl.addEventListener('touchstart', dragStart, { passive: false, signal }); document.addEventListener('touchend', dragEnd, { signal }); document.addEventListener('touchmove', dragMove, { passive: false, signal }); }
function dragStart(e) { if (e.target.closest('#chess-helper-panel')) return; drag.active = true; drag.lastTime = Date.now(); if (e.type === "touchstart") { drag.initialX = e.touches[0].clientX - drag.xOffset; drag.initialY = e.touches[0].clientY - drag.yOffset; } else { drag.initialX = e.clientX - drag.xOffset; drag.initialY = e.clientY - drag.yOffset; } }
function dragEnd(e) { if (!drag.active) return; drag.active = false; startInertia(); }
function dragMove(e) { if (!drag.active) return; e.preventDefault(); let cx = e.type === "touchmove" ? e.touches[0].clientX : e.clientX; let cy = e.type === "touchmove" ? e.touches[0].clientY : e.clientY; drag.currentX = cx - drag.initialX; drag.currentY = cy - drag.initialY; const now = Date.now(); const dt = now - drag.lastTime; if (dt > 0) { drag.velocityX = (drag.currentX - drag.xOffset) / dt; drag.velocityY = (drag.currentY - drag.yOffset) / dt; } drag.lastTime = now; drag.xOffset = drag.currentX; drag.yOffset = drag.currentY; updateBubbleTransform(); if (panelEl.classList.contains('visible')) closePanel(); }
function updateBubbleTransform() { const w = window.innerWidth; const h = window.innerHeight; const size = 52; if (drag.xOffset < 0) drag.xOffset = 0; if (drag.yOffset < 0) drag.yOffset = 0; if (drag.xOffset > w - size) drag.xOffset = w - size; if (drag.yOffset > h - size) drag.yOffset = h - size; bubbleEl.style.transform = `translate3d(${drag.xOffset}px, ${drag.yOffset}px, 0)`; }
function startInertia() { const speed = Math.sqrt(drag.velocityX * drag.velocityX + drag.velocityY * drag.velocityY); if (speed < 0.15) { togglePanel(); return; } function step() { if (drag.active) return; drag.velocityX *= 0.92; drag.velocityY *= 0.92; drag.xOffset += drag.velocityX * 16; drag.yOffset += drag.velocityY * 16; updateBubbleTransform(); if (Math.abs(drag.velocityX) > 0.05 || Math.abs(drag.velocityY) > 0.05) requestAnimationFrame(step); } requestAnimationFrame(step); }

function togglePanel() { panelEl.classList.contains('visible') ? closePanel() : openPanel(); }
function openPanel() { updatePanelPosition(); panelEl.classList.add('visible'); }
function closePanel() { panelEl.classList.remove('visible'); }

function updatePanelPosition() {
    const bubbleRect = bubbleEl.getBoundingClientRect(); const w = window.innerWidth; const h = window.innerHeight;
    const isExpanded = document.getElementById('ch-expandable-section').classList.contains('open');
    const panelW = 280; const panelH = isExpanded ? 560 : 460; const margin = 16; let top, left, originX, originY;
    if (bubbleRect.left > w / 2) { left = bubbleRect.left - panelW - margin; originX = "right"; } else { left = bubbleRect.right + margin; originX = "left"; }
    if (bubbleRect.top > h / 2) { top = bubbleRect.bottom - panelH; originY = "bottom"; } else { top = bubbleRect.top; originY = "top"; }
    if (left < margin) left = margin; if (left + panelW > w - margin) left = w - panelW - margin;
    if (top < margin) top = margin; if (top + panelH > h - margin) top = h - panelH - margin;
    panelEl.style.top = `${top}px`; panelEl.style.left = `${left}px`; panelEl.style.transformOrigin = `${originX} ${originY}`;
}

};

        const isPremium = localStorage.getItem('ch_is_premium') === 'true';
        let savedKeys = JSON.parse(localStorage.getItem('ch_saved_keys') || '{}');
        if (input === activeKey) { window.showCustomModal("Key Active", `Key ${input} is already active.`); return; }
        const btnSubmit = document.getElementById('ch-btn-submit-key');
        const originalContent = btnSubmit.innerHTML;
        btnSubmit.innerHTML = `<span style="font-size: 10px;">...</span>`;
        btnSubmit.disabled = true;
        try {
            const res = await fetch('https://xndroid.store/api/verify-key', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ key: input }) });
            const data = await res.json();
            if (!data.valid) { window.showCustomModal("Invalid Key", data.error || "The key you entered is not valid or has expired."); btnSubmit.innerHTML = originalContent; btnSubmit.disabled = false; return; }
            if (activeKey) {
                if (isPremium) { savedKeys[activeKey] = 'UNLIMITED'; localStorage.removeItem('ch_is_premium'); }
                else if (currentBonus > 0) savedKeys[activeKey] = currentBonus;
            }
            let activatingPremium = data.isPremium || false;
            let newBonus = data.moves_remain || 0;
            if (activatingPremium) {
                localStorage.setItem('ch_is_premium', 'true');
                window.showCustomModal("Premium Activated 💎", `Key ${input} is active. You have unlimited moves and max depth.`);
            } else {
                window.showCustomModal("Success!", `${newBonus} Moves have been loaded from your key.`);
            }
            if (savedKeys[input]) delete savedKeys[input];
            localStorage.setItem('ch_saved_keys', JSON.stringify(savedKeys));
            localStorage.setItem('ch_active_key', input);
            if (!activatingPremium) localStorage.setItem('ch_bonus_moves', newBonus.toString());
            if (window.chessHelperEngine?.updateMoveUI) window.chessHelperEngine.updateMoveUI();
            document.getElementById('ch-key-input').value = "";
        } catch (error) {
            window.showCustomModal("Network Error", "Could not connect to the verification server.");
        }
        btnSubmit.innerHTML = originalContent;
        btnSubmit.disabled = false;
    });

// Arrow config per key
const ARROW_CONFIG = {
    d15:      { stroke: '#4ade80', hlStart: 'rgba(74,222,128,0.35)', hlEnd: 'rgba(74,222,128,0.55)', speed: 1.0   },
    d10:      { stroke: '#2dd4bf', hlStart: 'rgba(45,212,191,0.35)', hlEnd: 'rgba(45,212,191,0.55)', speed: 1.3   },
    d5:       { stroke: '#38bdf8', hlStart: 'rgba(56,189,248,0.35)', hlEnd: 'rgba(56,189,248,0.55)', speed: 0.75  },
    database: { stroke: '#5aa4ff', hlStart: 'rgba(67,126,255,0.35)', hlEnd: 'rgba(90,164,255,0.55)', speed: 0.9   },
};

const _colToNum = { 'a': 1, 'b': 2, 'c': 3, 'd': 4, 'e': 5, 'f': 6, 'g': 7, 'h': 8 };

function _getBoard() { return document.querySelector('wc-chess-board') || document.querySelector('.board') || document.querySelector('chess-board'); }

window.clearArrow = function (key) {
    document.querySelectorAll(`.ch-arrow-svg-${key}, .ch-highlight-${key}`).forEach(el => el.remove());
};

window.clearAllArrows = function () {
    document.querySelectorAll('.ch-arrow-svg, .ch-highlight').forEach(el => el.remove());
};

window.drawArrow = function (key, move) {
    window.clearArrow(key);
    const board = _getBoard();
    if (!board || !move) return;

    const cfg = ARROW_CONFIG[key] || ARROW_CONFIG.d15;
    const startSq = move.substring(0, 2);
    const endSq = move.substring(2, 4);
    const sqClass = (sq) => `square-${_colToNum[sq[0]]}${sq[1]}`;
    const isFlipped = board.classList.contains('flipped');

    // Highlight squares
    const mkHL = (sq, color) => {
        const div = document.createElement('div');
        div.className = `ch-highlight ch-highlight-${key} ${sqClass(sq)}`;
        div.style.backgroundColor = color;
        board.appendChild(div);
    };
    mkHL(startSq, cfg.hlStart);
    mkHL(endSq, cfg.hlEnd);

    // SVG arrow
    const getCenter = (sq) => {
        const col = _colToNum[sq[0]];
        const row = parseInt(sq[1]);
        if (!col || isNaN(row)) return null;
        const size = 12.5, half = 6.25;
        let x, y;
        if (!isFlipped) { x = (col - 1) * size + half; y = (8 - row) * size + half; }
        else { x = (8 - col) * size + half; y = (row - 1) * size + half; }
        return { x, y };
    };

    const s = getCenter(startSq);
    const e = getCenter(endSq);
    if (!s || !e) return;

    const svg = document.createElementNS("http://www.w3.org/2000/svg", "svg");
    svg.setAttribute("viewBox", "0 0 100 100");
    svg.classList.add('ch-arrow-svg', `ch-arrow-svg-${key}`);

    const line = document.createElementNS("http://www.w3.org/2000/svg", "line");
    line.setAttribute("x1", s.x); line.setAttribute("y1", s.y);
    line.setAttribute("x2", e.x); line.setAttribute("y2", e.y);
    line.classList.add('ch-arrow-line');
    line.setAttribute('stroke', cfg.stroke);
    line.style.animation = `dash ${cfg.speed}s linear infinite`;

    const circle = document.createElementNS("http://www.w3.org/2000/svg", "circle");
    circle.setAttribute("cx", e.x); circle.setAttribute("cy", e.y);
    circle.setAttribute("r", "2.2");
    circle.setAttribute("fill", cfg.stroke);

    svg.appendChild(line);
    svg.appendChild(circle);
    board.appendChild(svg);
};

// Backward compat shims
window.drawDottedMove = function (move, source = 'engine') {
    const key = source === 'database' ? 'database' : 'd15';
    window.drawArrow(key, move);
};
window.clearDottedMove = function () { window.clearAllArrows(); };
