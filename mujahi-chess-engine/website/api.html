API Reference

Base URL: https://mujahi-chess.onrender.com. Evaluation values are normalized to White's perspective in pawns (+ favors White, - favors Black).

Endpoints

Method & Path Transport Purpose
GET /health JSON Container readiness, engine state, queue load, RSS memory, and uptime.
GET /v1/engine JSON Pinned Stockfish 19 tag, commit hash, SFNNv16 default net, and runtime limits.
POST /v1/analyze JSON Runs one iterative deepening search and returns all requested depth snapshots together.
POST /v1/analyze/stream SSE Emits started, progressive snapshot events as each depth completes, and complete.
GET /v1/analyze/stream SSE Query-parameter SSE variant (?fen=...&depths=5,10,15&clientSessionId=...) for EventSource clients.

Request: POST /v1/analyze

curl -X POST https://mujahi-chess.onrender.com/v1/analyze \
  -H "Content-Type: application/json" \
  -H "X-Client-Session-Id: client-tab-01" \
  -d '{
    "fen": "rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1",
    "depths": [5, 10, 15],
    "timeoutMs": 45000
  }'

Scheduler & Validation Guarantees

  • Session Isolation: Sending a new FEN with the same X-Client-Session-Id (or body clientSessionId) cancels only that client's stale queued/active search. Other users are unaffected.
  • FEN Deduplication: Concurrent identical FEN requests share the active calculation rather than spawning redundant searches.
  • Strict FEN Checks: Newline injection, invalid piece placement, missing/adjacent kings, side-not-to-move already in check, and illegal castling or en passant geometry return HTTP 400 before Stockfish receives input.
