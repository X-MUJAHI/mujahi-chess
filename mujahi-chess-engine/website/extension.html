Chess Helper Multi-Provider Architecture

Adds MUJAHI API as a third selectable provider alongside Chess Helper 2.1.0's existing Hosted API (StockfishOnline) default and Local WASM (Stockfish 19 Lite) modes.

Package & Adapter Availability

Selectable Providers in Chess Helper 2.1.0

Provider Key UI Label Execution Path Status
'api' Hosted API (StockfishOnline) Direct fetch to stockfish.online/api/s/v2.php Preserved as default
'wasm' Local WASM (Stockfish 19 Lite) Extension-origin engine/host.html dedicated worker Preserved as bundled
'mujahi' MUJAHI API (Stockfish 19) MV3 Background Service Worker → Render Docker API (SSE + JSON) Added via examples/ adapter

MV3 Service Worker Transport

Content scripts on Chess.com send FEN requests to the extension's Manifest V3 service worker (examples/extension-background.js). Because the extension declares Render's origin in manifest.json host_permissions, your Render API does not need to expose Chess.com in browser CORS.

Normalized Arrow & SuperMode Contract

examples/extension-provider.js outputs Chess Helper's exact engineAnalysisCache object shape: { move, evaluation, mate, continuation, depth, raw } with White-POV scores and stale-position rejection, so D5/D10/D15 arrows, mate detector, and SuperMode work identically.
